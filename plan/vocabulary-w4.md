# Day 1 (1日目): なんとか覚えよう！ (I'll try to memorize them!)

## Vocabulary — Adverbs of Certainty, Time, and Manner
* **必ずしも～とは限らない (かならずしも～とはかぎらない)** — not necessarily (e.g., Being rich does not necessarily mean happy.)
* **必ず (かならず)** — eventually / definitely / always
* **いつか** — someday / sometime
* **いつまでも** — forever / always
* **いつのまにか** — before one knows it / unawares
* **つい** — without meaning to / unintentionally
* **ついに** — finally / at last
* **どうしても** — no matter what / simply not possible
* **どうも** — somehow / really (cannot explain well) / much (thanks/excuse me)
* **なんとか／どうにか** — somehow / manage to do
* **なんとなく** — sort of / somehow
* **なんとも～ない** — not care about / think nothing of
* **もし（も）** — if
* **もしかしたら／もしかすると** — perhaps / possibly / could be
* **なるべく** — as much as possible / if you can
* **なるほど** — I see / certainly / indeed
* **確か (たしか)** — probably / I think / if I remember correctly
* **確かに (たしかに)** — definitely / certainly / surely

## Practice (練習)

**練習I — Choose the correct option:**
1. お金を貯めて、（a. つい / b. ついに）欲しい車を手に入れた。
2. 急げば、（a. なんとか / b. なんとなく）約束の時間に間に合うでしょう。
3. （a. 確か / b. なるほど）彼女は結婚したはずだけど……。
4. 彼のあの態度は（a. なるべく / b. どうしても）許せない。
5. ゲームに夢中になっていたら、（a. いつまでも / b. いつのまにか）朝になっていた。
6. （a. どうしても / b. どうも）風邪をひいてしまったらしい。

**練習II — Choose the word that fits:**
7. （ ）私は、昨日、5時まで会社にいました。間違いありません。 → 1 必ず 2 必ずしも 3 確か 4 確かに
8. このごみを（ ）しないと、座るところもない。 → 1 なんとも 2 なんとか 3 なるべく 4 なんとなく

*きょうの一言: 全部覚えるのは、必ずしも不可能ではありません。*

**Answers (Day 1):** 練習I ① b ② a ③ a ④ b ⑤ b ⑥ b ／ 練習II ⑦ 4 ⑧ 2

* **別に～ない (べつに～ない)** — not particularly
* **そう～ない** — not so much / not that
* **大して～ない (たいして～ない)** — not much / not very
* **一切～ない (いっさい～ない)** — absolutely not / none at all
* **とても～ない** — hardly / by no means
* **おそらく～だろう** — probably
* **どうやら～そうだ／ようだ** — seemingly / it looks like
* **果たして～だろうか (はたして～だろうか)** — really? / is it true that?
* **どうせ～だろう** — anyway / anyhow
* **せっかく～のに／から** — despite taking the trouble to / since we've gone to the trouble
* **いったん／一度／ひとたび～したら** — once (you do something)
* **いったん／ひとまず** — for now / for the time being (e.g. take a break, then resume)
* **かえって** — on the contrary / rather
* **さっそく** — immediately / right away
* **さすが（に）** — as expected / truly
* **あいにく** — unfortunately
* **あくまで（も）** — to the bitter end / persistently
* **なんだか／なんとなく／なぜか** — for some reason / somewhat
* **なんと／なんて** — what a / how
