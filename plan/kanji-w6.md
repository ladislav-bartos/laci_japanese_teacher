# Kanji Learning Summary - Week 6 (第6週：みる②)

This document extracts the essential Kanji information, vocabulary, and practice questions for Week 6, Days 1 through 7.

---

## Day 1: 広告・チラシ (Advertisements, Leaflets)

### 1. Kanji List & Vocabulary
* **得 (11 Strokes / トク / え・る, う・る):** 得 (とく - A profit/benefit), 得る (える - Obtain), 納得 (なっとく - Assent/understanding), 心得る (こころえる - Understand/be well aware).
* **告 (7 Strokes / コク / つ・げる):** 広告 (こうこく - An advertisement), 警告 (けいこく - Warning/caution), 告げる (つげる - Inform).
* **税 (12 Strokes / ゼイ):** 税金 (ぜいきん - A tax), 消費税 (しょうひぜい - A consumption tax), 税関 (ぜいかん - Customs), 課税 (かぜい - Taxation).
* **価 (8 Strokes / カ):** 定価 (ていか - A fixed price), 物価 (ぶっか - Price/cost of living).
* **格 (10 Strokes / カク):** 価格 (かかく - A price), 性格 (せいかく - Character/personality).
* **超 (12 Strokes / チョウ / こ・える, こ・す):** 超〜 (ちょう〜 - Ultra-/super-), 超える (こえる - Get over/exceed), 超過 (ちょうか - Excess/surplus), 超す (こす - Cross/pass/exceed).
* **均 (7 Strokes / キン):** 平均 (へいきん - An average), 均一 (きんいつ - Uniformity).
* **靴 (13 Strokes / くつ):** 靴 (くつ - Shoes), 長靴 (ながぐつ - Boots), 靴下 (くつした - Socks), 雨靴 (あまぐつ - Rain shoes).
* **供 (8 Strokes / キョウ / とも):** 提供 (ていきょう - An offer/a tender), 子供 (こども - A child).
* **象 (12 Strokes / ショウ, ゾウ):** 印象 (いんしょう - An impression), 対象 (たいしょう - Object [e.g. of study]), 現象 (げんしょう - A phenomenon), 象 (ぞう - An elephant).
* **組 (11 Strokes / く・む, くみ):** 組織 (そしき - An organization), 組み合わせ (くみあわせ - A combination), 番組 (ばんぐみ - A TV program), 組合 (くみあい - An association).
* **値 (10 Strokes / チ / ね, あたい):** 価値 (かち - Value/worth), 値段 (ねだん - A price), 数値 (すうち - A numerical value), 値 (ね - Value/price).
* **募 (12 Strokes / ボ / つの・る):** 募集 (ぼしゅう - Recruitment), 募金 (ぼきん - Fund-raising [money]), 応募 (おうぼ - An application), 募る (つのる - Collect/raise [money], recruit).
* **無 (12 Strokes / ム, ブ / な・い):** 無料 (むりょう - No charge), 無事 (ぶじ - Unharmed/safe), 有無 (うむ - Existence or nonexistence), 〜無し (〜なし - No...).

### 2. Practice Questions
* 消費税は商品に (**a.** 均等 / **b.** 平均) に課税される。
* 「広告が事実と異なり、(**a.** 心得 / **b.** 納得) がいかない場合はこちらにご連絡を。」
* 「〇〇ランドの入場者数がすでに百万人を (**a.** 超え / **b.** 告げ) ました。」
* 世界で最も (**a.** 定価 / **b.** 物価) の高い都市はどこでしょう。
* 子供を (**a.** 対象 / **b.** 対照) としたテレビ番組を制作する。
* コレステロールの (**a.** 数値 / **b.** 価値) が上がっているので注意してください。
* (**a.** 靴下 / **b.** 雨靴) は無いが、ぬれてもいい靴ならある。
* この番組は〇〇食品の (**a.** 提供 / **b.** 現象) でお送りしました。

* **破 (10 Strokes / ハ / やぶ・れる, やぶ・る):** 破格 (はかく - Exceptional), 破片 (はへん - A fragment), 破れる (やぶれる - Break/rip), 破産 (はさん - Bankruptcy), 破る (やぶる - Break/rip/violate [something]).
* **処 (5 Strokes / ショ):** 処理 (しょり - Disposal/processing), 処分 (しょぶん - Disposal/punishment), 処置 (しょち - Management/measure).
