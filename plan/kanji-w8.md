# Kanji Learning Summary - Week 8 (第8週：しる)

This document extracts the essential Kanji information, vocabulary, and practice questions for Week 8, Days 1 through 7.

---

## Day 1: 速報 (News Flash)

### 1. Kanji List & Vocabulary
* **州 (6 Strokes / シュウ):** 本州 (ほんしゅう - Honshu [main island of Japan]), 〜州 (〜しゅう - A state, e.g. the state of Texas), 九州 (きゅうしゅう - Kyushu).
* **波 (8 Strokes / ハ / なみ):** 電波 (でんぱ - A radio [wave]), 波 (なみ - A wave), 津波 (つなみ - A tsunami).
* **盗 (11 Strokes / トウ / ぬす・む):** 強盗 (ごうとう - A robbery), 盗む (ぬすむ - Steal), 盗難 (とうなん - A theft).
* **逃 (9 Strokes / トウ / に・げる, に・がす, のが・す):** 逃走 (とうそう - An escape/flight), 逃げる (にげる - Escape), 逃がす (にがす - Release/let go), 逃す (のがす - Let slip).
* **疑 (14 Strokes / ギ / うたが・う):** 疑問 (ぎもん - A question/doubt), 疑う (うたがう - Doubt/suspect), 容疑 (ようぎ - [Criminal] suspicion).
* **捕 (10 Strokes / ホ / つか・まる, つか・まえる, と・る, とら・える):** 逮捕 (たいほ - Arrest/capture), 捕まる (つかまる - Be arrested/be caught), 捕る (とる - Take/catch [fish]), 捕まえる (つかまえる - Arrest/catch), 捕らえる (とらえる - Seize/grasp/arrest).
* **絶 (12 Strokes / ゼツ / た・える, た・つ):** 絶対(に) (ぜったいに - Absolutely/definitely), 絶つ (たつ - Sever/cut off/suppress), 絶えず (たえず - Constantly).
* **党 (10 Strokes / トウ):** 政党 (せいとう - A political party), 与党 (よとう - The ruling party), 〜党 (〜とう - [Political] party), 野党 (やとう - The opposition party).
* **補 (12 Strokes / ホ / おぎな・う):** 候補(者) (こうほしゃ - A candidate), 補助 (ほじょ - Assistance/support), 補足 (ほそく - Supplement/complement), 補う (おぎなう - Compensate for/supplement).
* **童 (12 Strokes / ドウ):** 児童 (じどう - Children/juvenile), 童話 (どうわ - A fairy tale).
* **爆 (19 Strokes / バク):** 爆発 (ばくはつ - An explosion).
* **暴 (15 Strokes / ボウ / あば・れる):** 暴走 (ぼうそう - Running wildly), 暴れる (あばれる - Behave violently), 乱暴(な) (らんぼうな - Rude/violent).
* **亡 (3 Strokes / ボウ / な・い):** 死亡 (しぼう - Death), 亡くなる (なくなる - Die), 亡くす (なくす - Lose someone).
* **罪 (13 Strokes / ザイ / つみ):** 〜罪 (〜ざい - Crime of...), 有罪 (ゆうざい - Guilty), 無罪 (むざい - Innocent), 罪 (つみ - A crime).

### 2. 上回る・下回る (Exceed / Fall Below) — bonus vocabulary for reading graphs and tables

読めるかな？(Can you read this?)

**I グラフ (Graph)** — terms for describing a line graph's movement:
1. 増加する／上昇する (increase/rise)
2. 横ばい／一定 (level off/stay constant)
3. 大幅に上昇する (rise sharply)
4. 減少する／下降する (decrease/decline)
5. 著しく減少する／下降する (decrease/decline remarkably)
6. AはBを上回る (A exceeds B) ／ BはAを下回る (B falls below A) ／ Aが1位を占める (A occupies 1st place)
